refactor: adopt DDD layering, encapsulate Universe aggregate, add tests

Restructure the codebase into strict Domain-Driven Design layers and
resolve every remaining DDD violation identified in the audit.

Layer rules (no exceptions):
  domain       → zero imports from other internal packages
  application  → domain only
  infrastructure → domain only (implements its interfaces)
  interface/cli → sole composition root; wires all concrete impls

Dependency inversion
- navigation.Pathfinder interface stays in domain; BFSPathfinder (the
  concrete struct) moves to infrastructure/navigation — was the last
  concrete impl leaking into the domain layer
- universe.Repository and universe.LocationGenerator remain domain
  interfaces injected at App construction

Universe aggregate root encapsulation
- Locations and Edges maps are now unexported
- Public surface: EdgesFrom, AllLocations, AllLocationIDs, AllEdgesFlat
- Callers in application, infrastructure, and interface layers updated
  to use the new accessors; no more direct map indexing outside universe.go

Domain value-object methods
- TravelMode.IsPhysical() — distinguishes physical (walk/cycle/drive/
  rail/flight/orbit/warp) from non-physical (quantum/timeline/…) modes
- Coordinate.QuantumLevel() — parses Q{n} into an int; single source
  of truth, reused by Session and ShiftCommand

BranchQuantum domain service (universe/quantum.go)
- Idempotent function that creates a new quantum-branch location with
  bidirectional QuantumShift edges
- Removes quantum-creation logic from ShiftCommand (application layer)
  and places it where domain rules belong

Quantum travel commands
- `shift`      — jumps forward to the next quantum branch
- `shift back` — traverses the reverse edge to a lower branch level
- `travel`     — rejects any route that contains a non-physical edge;
                  quantum boundaries cannot be crossed on foot
- Display filters quantum edges from the regular journey list and shows
  contextual `shift` / `shift back` hints instead

Dead code removed
- internal/domain/universe/travel_plan.go (unused TravelPlan struct)
- internal/testutil/ (NewTestUniverse moved to internal/mocks/fixtures.go)

Tests
- 39 tests across application/commands, application/queries, interface/cli
- testify assertions; mocks generated by mockery (make mocks)
- .mockery.yaml configures MockRepository, MockPathfinder,
  MockLocationGenerator with EXPECT() API into internal/mocks/

Docker
- make docker-clean: `docker compose down --volumes --remove-orphans`
  for explicit cleanup of any dangling containers or anonymous volumes
